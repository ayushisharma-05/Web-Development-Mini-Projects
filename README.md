# Web Development Mini Projects

A collection of small web development projects built while learning and practicing core web technologies.

This repository is organized by technology, with each project maintained in its own folder.

## 📁 Projects

### 🟨 JavaScript

Basic JavaScript projects focused on DOM manipulation, events, and browser-based functionality.

- **Stopwatch**
  - Start, Pause, and Reset functionality
  - Time tracking using `setInterval()`
  - DOM manipulation and event handling

- **Image Swap**
  - Swap the main image by clicking on thumbnails
  - JavaScript functions and DOM manipulation
  - Event handling

### 🟩 Node.js

Mini projects created to practice server-side JavaScript and Node.js fundamentals.

- **HTTP Server**
  - Created using Node.js built-in `http` module
  - Handles incoming HTTP requests
  - Serves different HTML pages based on routes
  - Includes pages such as Home, About, Contact, Registration, and 404

- **CRUD Operation**
  - Basic Create, Read, Update, and Delete operations
  - Practicing server-side data handling with Node.js

- **Registration Form**
  - Registration form handling using Node.js
  - Demonstrates GET and POST request handling
  - Separate implementations for GET and POST methods
